# Product Inventory & Analytics Dashboard

A beginner-friendly inventory management web application built with HTML, CSS, and JavaScript.

## Features

- Add products with name and price
- Automatically categorize products as Budget, Standard, or Premium
- View total products and inventory value
- Search products by name
- Filter products by category
- Sort products by price
- Delete products from inventory
- Save inventory in browser local storage
- Export inventory data as a CSV report
- Responsive dashboard design

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6+)
- Browser Local Storage
- Git and GitHub

## Getting Started

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your browser, or use the Live Server extension in VS Code.

No additional packages are required.

## How to Use

1. Enter a product name and price.
2. Click **Add Product**.
3. View inventory statistics and product categories.
4. Use search, filtering, and sorting to manage products.
5. Export the inventory report as a CSV file.

## Storage

Products are saved in your browser's local storage. Data is not synchronized between browsers or devices.
